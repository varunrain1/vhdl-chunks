GNSS I/Q rotation and DDS mixer

Watch the incoming I/Q vector rotate, the DDS rotate the other way, and their complex product stay still.

\(f_s = 122.88\text{ MHz}\)
13-bit phase accumulator
FTW = round(\(f_{DDS}/f_s \times 8192\))

1. Incoming ADC signal

The tip moves counterclockwise. Its coordinates are I = A cos(θ), Q = A sin(θ).

Incoming vectorI = horizontal, Q = vertical

2. DDS correction vector

The DDS produces cos(ψ) − j sin(ψ), so it rotates clockwise.

DDS vectorNegative Q means clockwise rotation

3. Complex mixer output

Complex multiplication adds the two vector angles: output angle = input angle − DDS phase.

4. I and Q samples over time

The input traces oscillate. When correction frequency matches the input, output I/Q are constant (or constant at a nonzero phase).

What to try
  1. Keep both frequencies at 8.70 MHz. The input vector spins, the DDS spins backwards, and the output vector stays fixed.
  2. Set the initial phase to 60°. The output stays fixed but points at 60°: carrier wipeoff removes frequency, not unknown starting phase.
  3. Change DDS correction to 8.60 MHz. The output now rotates slowly at +100 kHz because 8.70 − 8.60 = 0.10 MHz.
Complex multiplication: \((I+jQ)(D_I+jD_Q)\)
\(I_{out}=I D_I-Q D_Q,\quad Q_{out}=I D_Q+Q D_I\)
\(f_{residual}=f_{input}-f_{DDS}\)
